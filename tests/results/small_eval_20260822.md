# 小规模 Agent 评测报告

测试日期：2026-08-22

本次使用真实 DeepSeek API，规模控制为少量样本；Redis、插件和调度测试不消耗模型 Token。

## 结果

| 指标 | 样本 | 通过 | 本轮结果 | 说明 |
|---|---:|---:|---:|---|
| 意图识别 | 5 | 5 | 100% | 单意图样本，严格匹配首个意图 |
| RAG 答案 | 3 | 3 | 100% | 检查预设关键事实，不等于完整语义准确率 |
| 偏好抽取 | 3 | 3 | 100% | 检查酒店、交通、预算三类偏好 |
| Redis 热缓存 | 10 | 10 | 100% | 同一用户偏好的 10 次热读，Redis 已连接 |
| 混合调度 | 1 场景 | - | 阶段耗时下降约 39.9% | 串行 14.15 秒，并行 8.51 秒 |

## 意图样本

```text
帮我规划明天上海到郑州的出差行程 → trip_planning
郑州有什么酒店 → real_time_query
公司出差住宿标准是什么 → policy_query
我喜欢住万豪酒店 → preference_update
我平时喜欢住什么酒店 → memory_query
```

## RAG 样本

```text
北京住宿标准 → 500元/晚、一线城市
差旅费用报销时间 → 30个自然日
机票预订时间 → 提前7-14天
```

## 重要结论

本轮结果只能说明小样本功能正常，不能证明简历中的长期指标：

```text
意图 90%+
RAG 95%
偏好记忆 95%
Redis 命中率 85%
整体耗时 30秒 → 15秒
```

原因是样本量太小、意图没有覆盖多意图和上下文追问、RAG 使用的是关键词事实判定、Redis 测的是预热后的缓存，且没有完整旧版基线。

另外，重复使用 `asyncio.run()` 调用 AgentScope 时出现了 httpx 客户端事件循环关闭警告，但本轮结果均成功；后续生产化时应统一复用异步事件循环。
